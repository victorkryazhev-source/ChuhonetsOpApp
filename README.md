# Операция Чухонец 41

Музыка, голос, билеты и фото кубика встроены в index.html. Можно открыть index.html напрямую, без сервера, либо загрузить файлы в GitHub Pages.

1. Распакуйте архив.
2. Загрузите index.html, sw.js, manifest.webmanifest и папку icons в корень репозитория.
3. В Settings → Pages выберите main и / (root).
4. После обновления сайта перезагрузите страницу Ctrl+F5.

Нажмите молнию: звучит диктор и появляется название. Нажмите «ОПЕРАЦИЯ ЧУХОНЕЦ 41»: начинается первый музыкальный трек и открывается первая сцена. Кнопка ♪ включает и выключает музыку.

Исправления: четырёхструнный бас с четырьмя колками; короткая бородка Чухонца; единый плавный контур рук и локтей; исправленные позы с басом, в волейболе и с телефоном; встроенные аудио и билеты; работающий показ и скачивание билетов.

При обгоне синий седан выпускает заметный шлейф выхлопа; Чухонец реагирует после появления дыма и высовывает голову и кулак из окна.

Борода Чухонца соединена с усами по фото. Кисти при игре: левая обхватывает гриф, правая играет на струнах над звукоснимателями.

Волейболистки смотрят друг на друга через сетку. Исправлен сгиб локтей и хват телефона у фотографирующей Ленок.

Последние правки: руки при волейболе и выборе карточек; видимые пассажиры седана и жесты Вицина перед ответом Чухонца; постоянный ремень баса; полная борода; убрано чёрное затемнение перед турбазой; новая расстановка сантехники.

Вступление озвучивается русским голосом устройства без изменения высоты тона, эха и роботизированной записи. Тембр зависит от установленных русских голосов. При отсутствии русского голоса название показывается без искусственного роботизированного звука.
